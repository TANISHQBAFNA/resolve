# Angular Material / Button
Angular Material buttons are native <button> or <a> elements enhanced with Material Design styling. A <button> element should be used whenever some action is performed.
Five button types from the Material 3 spec.
https://material.angular.dev/components/button/overview
Aliases: action, btn, call to action, cta, submit
Properties: Type: Elevated, Filled, Outlined, Text, Tonal; Label: Button; Disabled: false, true
