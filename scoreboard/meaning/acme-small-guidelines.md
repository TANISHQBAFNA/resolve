# Acme UI

Records here include payees and savings.

## Card List
A list of cards, and the plain list when the thing listed is not a record in this library.

## Compact List
The compact list of records such as payees. Also called dense or tight.

## Comfortable List
The comfortable list of records such as savings. Also called roomy, spacious, or airy.

## Mobile Nav
Navigation for a phone.

## Desktop Nav
Navigation for a desktop.

## Button
An action control.

## Data Table
Rows and columns of data.

## Summary Card
A card of totals.

## Stat Block
One metric figure.

## Text Field
A field for text.

## Pay CTA
The control that pays a payee.

## Save CTA
The control that saves.

## Search Field
Finds a payee by name.

## Empty Message
Shown when nothing is here.

## Error Alert
A message when something failed.

## Pending Banner
A banner while work is pending.

## Loading Spinner
A spinner while loading.
